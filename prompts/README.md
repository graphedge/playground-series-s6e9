# Prompts Directory

## Purpose

Brett wants most text Q&As answered in `prompts/` (this repository), not in Stack0-datasci chat. Speckit and agents should read `prompts/` first before asking questions or requesting clarification.

## Files

- **FAQ.md** — Frequently asked questions about the competition, data, and workflows
- **OPEN.md** — Open questions that remain unanswered (do not invent answers to these)

When in doubt, check these files before asking. If a question is not documented, it may belong here.
